# Deposit Digital v1.12.1

แอป PWA บันทึกเงินฝากหลายธนาคาร ข้อมูลเข้ารหัส AES-256-GCM เก็บในเครื่อง (localStorage) สำรองขึ้น Google Sheets / Drive ผ่าน Apps Script

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป (แก้ `VER`) |
| `tw.css` | CSS ที่ build จาก Tailwind แล้ว (ใช้ออฟไลน์ได้ทันที ไม่ต้องพึ่ง CDN) |
| `src/input.css` | ต้นฉบับ CSS + ธีม Cyber-Gold / Dark Neon |
| `sw.js` | Service Worker (แก้ `VERSION`) |
| `Code.gs` | Backend ของ Google Apps Script |
| `package.json` | สำหรับ build CSS ใหม่ |

## ใช้งาน
อัปโหลดทุกไฟล์ (ยกเว้น `src/` และ `package.json` ก็ได้) ขึ้นโฮสต์ที่เป็น HTTPS เปิดครั้งแรกขณะออนไลน์ หลังจากนั้นใช้ออฟไลน์ได้

## แก้ธีม / เพิ่มคลาส Tailwind แล้ว build CSS ใหม่
```
npm install
npm run build:css
```
ต้องใช้ Tailwind v4 (รองรับ Safari 16.4+ / Chrome 111+ / Firefox 128+)

## ปล่อยเวอร์ชันใหม่
1. แก้ `VER` ใน `index.html` และ `VERSION` ใน `sw.js` ให้ตรงกัน
2. อัปโหลดไฟล์ทับ ผู้ใช้จะเห็นแถบ "มีเวอร์ชันใหม่ [อัปเดต]" เอง (เช็กทุก 30 นาทีและทุกครั้งที่เปิดแอป) หรือกด "ตรวจหาเวอร์ชันใหม่" ที่ ตั้งค่า > สถานะ

## ตั้งค่า Apps Script
1. ในแอป ตั้งค่า > สำรอง/กู้คืน กด "🎲 สร้าง Token สุ่ม" (คัดลอกให้อัตโนมัติ) แล้วกด "บันทึกค่า"
2. เปิด Google Sheet > Extensions > Apps Script วางเนื้อหา `Code.gs`
3. Project Settings > Script properties เพิ่ม `TOKEN` = ค่าที่คัดลอกไว้ (หรือรัน `setupToken()` ในตัวแก้ไข แล้วนำ Token จาก log ไปใส่ในแอป)
4. Deploy > New deployment > Web app (Execute as: Me, Access: Anyone) นำ URL `/exec` ไปใส่ในแอป
- Token สั้นกว่า 24 ตัวอักษรจะถูกปฏิเสธทั้งสองฝั่ง
- ต้องตั้งรหัสผ่านสำรองก่อนจึงสำรองได้ และเซิร์ฟเวอร์รับเฉพาะไฟล์ที่เข้ารหัสด้วยรหัสนี้
- เปลี่ยน Token แล้วต้องแก้ทั้งในแอปและ Script properties ให้ตรงกัน

## v1.12.0 มีอะไรใหม่
- **เปลี่ยนชื่อ “เป้าเงินฝากสะสม” → “เป้าหมายการออม”** (การ์ดหน้าแรก + หน้าตั้งค่า) และเอาข้อความประมาณการวันถึงเป้า / ดอกเบี้ยสุทธิเฉลี่ย / เงินสะสมเพิ่มเฉลี่ย / “รวมตั้งแต่ต้น” ออกทั้งหมด เหลือเป้า, เปอร์เซ็นต์, แถบความคืบหน้า และยอดที่เหลือ
- **การ์ด “ดอกเบี้ยปี {ปี}” (หน้าแรก)** ใช้รูปแบบเต็มของการ์ดดอกเบี้ยสะสมเดิม: เทียบปีที่แล้ว, ภาษีที่หักจริง, ถึงกำหนดเกณฑ์เสียภาษี (ประมาณ), ได้ดอกเบี้ยสุทธิ (ประมาณ), เฉลี่ยต่อเดือน + แถบเทียบเกณฑ์ภาษี
- **การ์ด “🏆 ฝากที่ไหนคุ้มสุด (ประมาณการ)”** แทน “ดอกเบี้ยสูงสุด” แสดงทุกธนาคาร จัดอันดับ 🥇🥈🥉 ตามผลตอบแทนสุทธิต่อปีหลังภาษี (ออมทรัพย์รวมทุกธนาคารเกินเกณฑ์จึงถูกหัก, ฝากประจำ/อื่น ๆ หักเสมอ)
- **หน้าสรุปยอด:** เอาการ์ด “ดอกเบี้ยสะสม”, “ดอกเบี้ยรวมแยกธนาคาร” และเป้าหมายการออมออก
- **ลำดับการ์ดหน้าแรก:** ยอดรวม → แจ้งเตือนยอดติดลบ → ปุ่มลัด → ใกล้ครบกำหนดฝาก → เป้าหมายการออม → ดอกเบี้ยปี → ฝากที่ไหนคุ้มสุด → ธุรกรรมล่าสุด
- ธีม Cyber-Gold / Dark Neon: เพิ่มสไตล์แถวอันดับ 1 เรืองแสงนีออน (`.rk`, `.rk1`) ใน `src/input.css` และ `tw.css`

## v1.11.0 มีอะไรใหม่

- ย้ายแถบเทียบเกณฑ์ภาษีไปอยู่ในการ์ด “ภาษีหัก ณ ที่จ่าย”

## v1.9.0 มีอะไรใหม่: นำเข้าข้อมูลย้อนหลังจาก CSV
ตั้งค่า > นำเข้าข้อมูลจาก CSV > "📥 นำเข้า CSV" (กด "📄 ไฟล์ตัวอย่าง" เพื่อดาวน์โหลดแม่แบบ)

คอลัมน์ (บรรทัดแรกเป็นหัวตาราง): `วันที่, ธนาคาร, ผลิตภัณฑ์, ประเภท, จำนวนเงิน, บันทึก` (บันทึกไม่บังคับ ใช้หัวคอลัมน์ภาษาอังกฤษ date, bank, product, type, amount, note ได้)
- **วันที่:** `ปปปป-ดด-วว`, `วว/ดด/ปปปป` และปี พ.ศ. (แปลงเป็น ค.ศ. ให้อัตโนมัติ)
- **ประเภท:** ยอดยกมา, ฝาก, ถอน, ดอกเบี้ยเงินฝาก, ภาษีหัก ณ ที่จ่าย, ปรับปรุงยอด (ค่าลบได้เฉพาะปรับปรุงยอด) ส่วนการโอนให้บันทึกเป็น ถอน + ฝาก
- **จำนวนเงิน:** ใส่ ฿ หรือคอมมาได้
- ชื่อธนาคาร/ผลิตภัณฑ์เทียบแบบไม่สนตัวพิมพ์เล็กใหญ่และช่องว่าง ถ้าไม่พบจะสร้างบัญชีให้ (ปิดได้)
- รายการที่ซ้ำกับที่มีอยู่ (วันที่ + บัญชี + ประเภท + จำนวนเงิน) จะถูกข้าม จึงนำเข้าไฟล์เดิมซ้ำได้อย่างปลอดภัย
- หน้าตรวจก่อนนำเข้าแสดงจำนวนรายการ แถวผิดพลาด และบัญชีที่ยอดจะติดลบ
- ไฟล์ต้องเป็น UTF-8 ไม่เกิน 2 MB และ 5,000 แถวต่อครั้ง (Google Sheets: ไฟล์ > ดาวน์โหลด > CSV, Excel: บันทึกเป็น "CSV UTF-8")
